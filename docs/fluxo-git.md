# Fluxo no GitHub

- A branch principal só recebe merge de feature.
- O nome da branch descreve a feature, no formato `feature/<assunto>`.
- Cada feature fica com a pessoa responsável pela área.
- Commits curtos, no imperativo, descrevendo uma mudança só.
- Pull request com descrição, critério de aceite e revisão de outro integrante.
- Não se commita direto na branch principal.
