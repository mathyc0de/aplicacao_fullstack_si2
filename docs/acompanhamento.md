# Acompanhamento

O quadro de trabalho segue as tarefas importadas no Jira. O histórico diário
de código está nas branches `feature/*`, com autoria separada por integrante.

Impedimentos tratados no período:

- bases oficiais grandes demais para versionar;
- necessidade de colaborador no repositório privado para cada conta;
- desktop mantido fora do Compose para não misturar com a entrega obrigatória.
