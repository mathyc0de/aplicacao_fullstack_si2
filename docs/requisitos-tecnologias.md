# Tecnologias obrigatórias

- API em Python com Flask, servida por Gunicorn.
- PostgreSQL para o armazenamento e a busca.
- Frontend web com HTML, CSS e JavaScript.
- Docker e Docker Compose para PostgreSQL, backend e frontend.
- Consultas parametrizadas, sem concatenar entrada do usuário em SQL.
- O cliente desktop é opcional e fica fora do Compose.
