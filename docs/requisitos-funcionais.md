# Requisitos funcionais

A aplicação consulta servidores do Executivo Federal.

- Busca por nome exato.
- Filtros por cargo, UF e órgão.
- Combinação desses filtros na mesma consulta.
- Padrões de similaridade `%NOME%SOBRENOME%`, `NOME SOBRENOME%` e `NOME%SOBRENOME`.
- Limite máximo de nomes e paginação.
- Respostas JSON e códigos HTTP coerentes.
- Interface web com filtros, resultados e navegação de páginas.
